# 阶段① 启动指南

这一页教你怎么在本机把「阶段① 对话 Agent」跑起来。

---

## 一、你的环境现状（已确认）

| 工具 | 状态 | 位置 / 说明 |
|------|------|-------------|
| Python | ✅ 3.12 | `C:\Users\user\AppData\Local\Programs\Python\Python312\python.exe` |
| Git | ✅ 已装 | F 盘 |
| API Key | ✅ 有 | DeepSeek |
| Docker | ❌ 未装 | 阶段④才需要，暂不用 |

## 二、虚拟环境（已经帮你建好）

项目里的 `.venv` 就是虚拟环境，依赖已经装好：
- langchain-core 1.6.9
- langchain-openai 1.7.0
- openai 3.26.1
- python-dotenv

> 说明：如果以后换电脑或重装，用下面命令重建环境：
> ```
> python -m venv .venv
> .venv\Scripts\python.exe -m pip install -r requirements.txt
> ```
> 注意：装 langchain-openai 时如果卡住，用 `pip install --no-deps langchain-openai` 跳过依赖重装。

## 三、配置 API Key（你只需要做这一步）

1. 复制模板：
   ```
   copy .env.example .env
   ```
2. 用记事本打开 `.env`，把这一行：
   ```
   DEEPSEEK_API_KEY=在这里填你的key
   ```
   改成你真实的 DeepSeek API Key（例如 `sk-xxxxxx`）。

## 四、运行

```
.venv\Scripts\python.exe src\app.py
```

看到下面这行就说明启动成功：
```
CloudOps Agent 已启动（阶段① 最小对话版）
```

然后就可以跟它对话了，输入 `quit` 退出。

## 五、验证"多轮记忆"是否生效

试这个对话，看它能否记住上下文：

```
你 > 我叫小明，我最近在学 Kubernetes
Agent > （它应该回应你，并且记住你叫小明）
你 > 我叫什么名字？
Agent > 你叫小明（这说明"记忆"生效了 ✅）
```

如果它能答出"你叫小明"，就说明阶段①的多轮记忆功能正常。
